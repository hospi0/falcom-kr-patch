## 핵심 사실
- 게임마다 `0xxxL.BIN`(저 워크램 0x00200000 이미지) + `1xxxH.BIN`(고 워크램, 이스 I 은 0x06004000 적재). 1편 메뉴 = 루트 `0`(0x06006000), 2편 메뉴 = `SUN/0FC2L·1FC2H`.
- **공용 압축 = [풀린 크기 u32 BE] + 오쿠무라 LZSS**(`tools/lzss.py`, 다크 세이비어와 같은 규약). SEGA CMP 아님. 그림 표가 블록을 가리키고 블록은 빈틈없이 이어짐 → 다시 압축 길이 ≤ 원래 칸.
- 대사 코드(이스 I·II·아스테카): u16 BE, 영문 = 문자−49, 가나 0x30‥0xDF(JIS 순), 한자 **0xE0‥**(게임별 배열, 아틀라스 순서 그대로), 0x0FFD 줄 · 0x0FFE 페이지 · 0x0FFF 끝.
- **이스 I 글꼴**: 글꼴 표 L 0xA0E14 = [폭 높이 폭 높이][아틀라스 주소] × 11. 16×16 아틀라스 = 0x8E9D4(코드 0‥2F) · 0x8F5D4(30‥DF) · 0x921D4(**0xE0‥**, 524자 — 옛 기록 «0x100‥528» 은 틀림). 형식 = **폭 256px 2bpp 한 장**(글자 16개/줄), 값 1 글자·3 그림자. 그리는 코드 0x06015D60.
- 스테이트(RetroArch Beetle): VDP1 VRAM 도 swap16 해야 명령표가 읽힌다(`tools/vdp1cmd.py`). 스테이트 덤프 `tools/state.py` → `work/mem/<이름>/`.
