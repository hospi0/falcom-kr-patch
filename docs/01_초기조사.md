## 두 디스크의 공통 틀 (같은 엔진 근거)
- 게임마다 `0xxxL.BIN` **1,048,576 B** + `1xxxH.BIN` **679,936 B(0xA6000)** 짝 = 새턴 저/고 워크램 통째 이미지. FC1·FC2 다섯 게임 + 두 메뉴 모두 같은 크기.
- 모든 `1xxxH.BIN` 의 **앞 0x2000 B 가 바이트 단위로 같다**(공용 시작 코드).
- 모든 `1xxxH.BIN` 에 **같은 0xA00 B 블록**(SJIS 코드를 11개 간격으로 늘어놓은 표 `81 08 81 13 …` 포함)이 0x9xxx 근처에 있다 — 공용 라이브러리. FC1 루트 `0` 에도 있다.
- `SOUND.DRV` 는 FC1 26,610 B / FC2 25,190 B (판이 다름).

## 다른 점
- FC1: 게임마다 `LLOADER3.BIN`·`LALLEND.BIN`(공용), 소리 = CD-DA 트랙 + `*SND*.DAT`.
- FC2: 루트에 `0FC2LOAD/0YS2LOAD/0SUNLOAD.BIN`(각 31,936 B, 서로 다름), 소리 = ADX·MP3, 동영상(`MOV*`, `*.CAK`). → 같은 틀의 **나중 판**.

## 텍스트 (미확정)
- 평문 SJIS 대사는 어느 이미지에도 없다(SJIS 덩어리 = 표·쓰레기뿐. DRS H 에 개발기 사전 찌꺼기 「打つ…strike」).
- **재너두**: `1ZANAH.BIN` 에 **반각 가타카나** 0 끝 문자열 — 무기·마법(0x90628‥, 20 B 레코드 `ｼｮｰﾄｿｰﾄﾞ`…)·가게 이름(0x880B4‥)·입력판(0x87D0E). PC-88 원본 자료 그대로로 보인다.
- 이스·이스 II·아스테카·드래곤 슬레이어: 「アドル」「リリア」 등을 SJIS·EUC·JIS·UTF-16·반각으로 찾아도 없음 → 압축이거나 자체 코드. `YS1/MD*.BIN`·`YS2/DAT*`·`MAP*`·`SUN/MD.BIN` 은 그림.

## 다음
- 게임별로 **대사가 떠 있는 세이브스테이트**를 받아 RAM 에서 대사 바이트·VRAM 에서 글꼴 경로를 찾는다(정적 검색보다 빠름).

## 2026-10-03 이스 I 스테이트 7개(work/mem/s1‥s6, s5b — 원본 스테이트 파일은 사용자가 옮김)
- **대사 = u16 빅엔디언 글자 코드**, `0YS1L.BIN`(= 저 워크램) 0x7B000‥0x88000 부근에 평문처럼(디스크 그대로). 예 0x86CE0 「私の父は、東の方のゼピック村で/村長をやっています。」
  - 알파벳 = 문자 − 49 (A=0x10, S=0x22), `-`=0x0C, 히라가나 あ=0x31 い=0x33 が=0x3B す=0x48 せ=0x4A っ=0x52 て=0x55 で=0x56 の=0x5D は=0x5E ま=0x6D や=0x73 り=0x79 を=0x7E ん=0x7F, 가타카나 ク=0x8E ゼ=0x9B タ=0x9E ッ=0xA2 デ=0xA6 ピ=0xB3, ー=0xD1 、=0xD2 。=0xD3, 한자 0x100 이상(私=0x180 村=0x1F5 長=0x216 東=0x22A 父=0x261 方=0x27E)
  - 제어: 0x0FFD 줄바꿈 · 0x0FFE 페이지 · 0x0FFF 끝 · 0x0FE0/0x0FE4 등
- **같은 코드표**: 「データが、ありません。」 = `A6 D1 9E 3B D2 31 79 6D 4A 7F D3` 가 이스 I(0x7BBCA)·**이스 II(0x467A8) 에 바이트 그대로**, 아스테카(0x126E8)도 「、ありません。」 부분 같음. 흔한 코드 순위(の·、·。·い·を·て)도 세 게임 같음. 재너두는 순위가 전혀 달라 다른 체계(반각 가나).
- 한자 코드가 게임끼리 같은지는 미확정(한자 포함 6글자 열 겹침이 적음 → 게임마다 한자 배열이 다를 가능성).
- **그리기**: 대사 상자 = VDP1 스프라이트 하나(256×52 4bpp, VRAM 0x12C20, 명령 10) 에 CPU 가 글자를 그림(색1 잉크 + 색3 그림자 +1,+1). VDP1 VRAM 은 이 게임 스테이트에서 **swap16 해야** 명령표가 읽힌다(다크 세이버와 반대).
- **글꼴 원본 못 찾음**: 「私」 16×16 모양을 1bpp(행 8·12·14·15·16비트)·4bpp·바이트 뒤집기로 RAM·VRAM·디스크 이미지 전부 찾았으나 없음 → 압축이거나 필요할 때 CD 에서 읽는 듯. 다음 = 글꼴 쓰기 중단점 또는 다른 장면 스테이트 대조.
